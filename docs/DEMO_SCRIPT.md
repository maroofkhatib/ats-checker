# Demo GIF script (about 25 seconds)

Goal: show the whole loop in one take: upload, score, add missing skills, score goes up, save the file with the original design.

## Before recording

- **Use a CV that isn't yours** (a sample or a friend's with permission). Never record real contact details, and blur or crop any you can't avoid.
- Best case: a `.docx` with a photo or coloured headings, so "your design is kept" is visible. Prepare one that is missing 3 to 5 skills the job asks for.
- Prepare a job description that is realistic and short enough to paste in one go. Put it on the clipboard.
- Wake the Render site (open it once) so you don't record the 30-second cold start. Or record against `http://localhost:3000`.
- Browser at 1280 x 720, zoom 100%, bookmarks bar hidden, dark notifications off, light theme (reads better in a GIF).
- Tools: ScreenToGif (Windows, free) or the Xbox Game Bar (`Win + G`) then convert to GIF. Aim for under 10 MB: 12 to 15 fps, 800 px wide.

## Shots

| Time | What you do | What the viewer should see |
|---|---|---|
| 0-3 s | Open the home page. | Clean landing page with the upload box and job description area. |
| 3-7 s | Drag the .docx onto the upload box, paste the job description, click **Check**. | File name appears, then the score animating in. |
| 7-11 s | Slowly scroll to the breakdown and missing skills. | Score out of 100, skills / experience / education / format bars, list of missing skills. |
| 11-15 s | Tick 3 to 4 skills, click **Add selected skills & re-score**. | Old score next to the new, higher score. |
| 15-21 s | Click **Save my original CV with the new skills**; in the Save window pick Desktop and press Save. | The system "Save as" window opening. |
| 21-25 s | Open the saved file in Word. | Same design, photo and fonts as before, with the new skills in the Skills section. Pause 2 s on it. |

## Tips

- Move the mouse slowly and pause about 1 second after each click so the GIF is readable.
- If the AI step is on and a skill is credited as "inferred", hover on it for a moment: it's the most interesting feature.
- Make a second, 10-second cut (shots 2 to 4 only) for the top of the README; the full one goes in the LinkedIn post.
- Save as `docs/demo.gif`, then uncomment the image line near the top of `README.md`.
- A LinkedIn post can also take a short MP4, which is usually sharper than a GIF and plays automatically.
